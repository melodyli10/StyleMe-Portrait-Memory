# Final evaluation protocol

1. Check the five development portraits and freeze the retouch rules before held-out scoring. Do not use the held-out set for debugging or tuning. If Face Slimming is not sufficiently functional on the development set, document that limitation and leave formal measurements pending.
2. Confirm exactly five development photos in Teach StyleMe. Record the build/commit used. Keep ten distinct held-out photos separate. File digests block exact duplicates, not all re-encoded copies.
3. Open Evaluation and start a new two-parameter session. Define acceptable eye/face appearance, artifacts and skip/failure interpretation before locking the profile and ten-photo dataset. Do not revise these definitions after seeing results.
4. Process each of the same ten cases through Fixed Preset and StyleMe Smart Style. The Lab randomizes anonymous A/B mapping; the same local pixel engine is used for both. Do not inspect method identity during scoring.
5. For EACH anonymous output, score Eye Enlargement: 0 if no further manual adjustment is required, 1 if adjustment is required. Score Face Slimming independently using the same definition. Per-output total is 0–2. Preview any final correction before locking its score. Record visible artifacts and the final accepted setting. One setting counts once regardless of slider movements.
6. Record skipped/failed cases explicitly, including reasons. Unsafe geometry or processing failures are not successful zero-correction outputs. Held-out processing must never update the teaching profile.
7. Review all ten outcomes, finalize, then reveal mappings and export JSON. Locked scores cannot be edited. Existing eye-only version-1 records remain unchanged; they do not become two-parameter evidence.
8. Aggregate only matched successful pairs. Sum baseline correction units and StyleMe correction units, divide each by the paired case count for means, and report that count out of ten. Compute `(FixedPresetCorrections - StyleMeCorrections) / FixedPresetCorrections × 100%`. If the baseline is zero or no pairs succeed, report the percentage as undefined. Retain skip/failure counts and artifacts separately.
9. Compare the measured reduction with the >=30% proposal target. Do not claim the target was reached before scoring. The author evaluates their own preferences; shuffled anonymous presentation does not completely remove bias.

Photographs are selected locally and are not persisted by the Lab. Numeric records/digests and free-text notes stay in localStorage; avoid identifying details. JSON export is an explicit download, not publication. Store private exports outside the public repository.
